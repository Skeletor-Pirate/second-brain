# Command: /review

Generate a Weekly Second Brain Review:
1. Aggregate all daily notes from `05_Daily_Notes/` for the past 7 days.
2. Summarize key achievements, completed project milestones, and added resource notes.
3. Identify stale projects in `01_Projects/` and recommend archive candidates.
4. Write the review note to `06_System/Weekly_Review_YYYY-WW.md`.
