# 📚 Resource: OmniRouter CheatSheet

OmniRouter is your unified LLM router and API gateway.

## ⚡ Useful CLI Commands
- `omniroute status` — Check server status & active routes.
- `omniroute launch` — Launch Claude CLI routed through OmniRouter.
- `omniroute setup-claude` — Generate Claude profiles for supported models.
- `omniroute doctor` — Run diagnostics on local setup.
- `omniroute dashboard` — Launch the web dashboard.
