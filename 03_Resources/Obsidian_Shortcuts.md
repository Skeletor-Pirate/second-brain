# 📚 Resource: Obsidian Shortcuts & Tips

## ⌨️ Key Bindings
- `Ctrl + O`: Quick Switcher (find any note instantly).
- `Ctrl + E`: Toggle Edit / Reading view.
- `Ctrl + G`: Open Graph View.
- `[[`: Create Wikilink to another note.
- `![[`: Embed another note or image.
